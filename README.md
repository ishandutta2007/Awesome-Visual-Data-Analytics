## 🔓 Open-Source GitHub Projects

Visual data analytics is one of the most vibrant open-source domains. Below are top open-source projects sorted in **descending order by GitHub_Stars_Count**.

---

### 📊 Full-Featured BI & Dashboard Platforms

- **[Grafana](https://github.com/grafana/grafana)** [<img src="https://img.shields.io/github/stars/grafana/grafana?style=social&color=white" alt="Grafana Stars"/>](https://github.com/grafana/grafana/stargazers) 🌟
  **The de facto standard for open-source operational dashboards**, AGPL-3.0 licensed. Connects to 100+ data sources including Prometheus, Loki, Tempo, Elasticsearch, PostgreSQL, and MySQL. Features rich visualization libraries, ML-powered alerting, and anomaly detection. **Best for operational monitoring & observability dashboards.**

- **[Apache Superset](https://github.com/apache/superset)** [<img src="https://img.shields.io/github/stars/apache/superset?style=social&color=white" alt="Superset Stars"/>](https://github.com/apache/superset/stargazers) 🌟
  **The leading enterprise open-source data exploration and visualization platform**, Apache-2.0 licensed. Superset 5.0 delivers 60+ chart types, a SQL IDE with Jinja templating, semantic modeling, an AI-powered intelligence layer, and an MCP server for LLM integration. **Best for enterprise open-source BI.**

- **[Metabase](https://github.com/metabase/metabase)** [<img src="https://img.shields.io/github/stars/metabase/metabase?style=social&color=white" alt="Metabase Stars"/>](https://github.com/metabase/metabase/stargazers) 🌟
  **User-friendly open-source BI and self-service analytics**, AGPL-3.0 licensed. Features an intuitive visual question builder allowing non-technical users to query data without SQL, alongside automated dashboards, alerts, and report subscriptions. **Best for non-technical team self-service analytics.**

- **[Redash](https://github.com/getredash/redash)** [<img src="https://img.shields.io/github/stars/getredash/redash?style=social&color=white" alt="Redash Stars"/>](https://github.com/getredash/redash/stargazers) 🌟
  **SQL-driven data visualization and collaborative dashboarding**, BSD-2-Clause licensed. Built for engineers and data analysts to write SQL, query diverse databases, visualize results, and share query templates across teams. **Best for SQL-first team dashboarding.**

- **[Appsmith](https://github.com/appsmithorg/appsmith)** [<img src="https://img.shields.io/github/stars/appsmithorg/appsmith?style=social&color=white" alt="Appsmith Stars"/>](https://github.com/appsmithorg/appsmith/stargazers) 🌟
  **Open-source low-code platform for building custom internal tools and executive dashboards**, Apache-2.0 licensed. Drag-and-drop UI widgets connected to databases and APIs with custom JavaScript logic. **Best for custom internal analytics apps.**

- **[ToolJet](https://github.com/ToolJet/ToolJet)** [<img src="https://img.shields.io/github/stars/ToolJet/ToolJet?style=social&color=white" alt="ToolJet Stars"/>](https://github.com/ToolJet/ToolJet/stargazers) 🌟
  **Extensible open-source low-code framework to build analytics apps and admin portals**, AGPL-3.0 licensed. Connects seamlessly to PostgreSQL, Snowflake, Google Sheets, and REST endpoints with pre-built charts and table controls. **Best for internal dashboard automation.**

- **[Lightdash](https://github.com/lightdash/lightdash)** [<img src="https://img.shields.io/github/stars/lightdash/lightdash?style=social&color=white" alt="Lightdash Stars"/>](https://github.com/lightdash/lightdash/stargazers) 🌟
  **Open-source Looker alternative built specifically for dbt workflows**, MIT licensed. Transforms dbt project semantic layers and YAML metric definitions into self-service BI dashboards for business users. **Best for dbt-centered data teams.**

### 🛠️ Embedded & Developer-Focused Analytics

- **[Streamlit](https://github.com/streamlit/streamlit)** [<img src="https://img.shields.io/github/stars/streamlit/streamlit?style=social&color=white" alt="Streamlit Stars"/>](https://github.com/streamlit/streamlit/stargazers) 🌟
  **Faster way to build and share custom data apps in Python**, Apache-2.0 licensed. Turns Python scripts into interactive, web-based analytics web applications in minutes without requiring frontend web development experience. **Best for data science & machine learning web apps.**

- **[Cube](https://github.com/cube-js/cube)** [<img src="https://img.shields.io/github/stars/cube-js/cube?style=social&color=white" alt="Cube Stars"/>](https://github.com/cube-js/cube/stargazers) 🌟
  **Universal open-source semantic layer for data applications and headless BI**, MIT licensed. Standardizes metric definitions across organizations and serves data via SQL, REST, GraphQL, and MDX APIs. **Best for headless BI & embedded analytics.**

- **[Evidence.dev](https://github.com/evidence-dev/evidence)** [<img src="https://img.shields.io/github/stars/evidence-dev/evidence?style=social&color=white" alt="Evidence Stars"/>](https://github.com/evidence-dev/evidence/stargazers) 🌟
  **Code-based BI and business intelligence framework**, MIT licensed. Enables data teams to craft fast, interactive dashboard reports using Markdown and SQL, stored cleanly inside Git repositories. **Best for BI-as-code & version-controlled reporting.**

- **[Perses](https://github.com/perses/perses)** [<img src="https://img.shields.io/github/stars/perses/perses?style=social&color=white" alt="Perses Stars"/>](https://github.com/perses/perses/stargazers) 🌟
  **CNCF dashboard and visualization tool**, Apache-2.0 licensed. Provides GitOps-friendly, dashboard-as-code capabilities aimed at establishing open standards for cloud-native metrics visualization. **Best for Kubernetes & GitOps observability.**

### ⚡ Analytical Databases & OLAP Engines

- **[ClickHouse](https://github.com/ClickHouse/ClickHouse)** [<img src="https://img.shields.io/github/stars/ClickHouse/ClickHouse?style=social&color=white" alt="ClickHouse Stars"/>](https://github.com/ClickHouse/ClickHouse/stargazers) 🌟
  **The leading open-source columnar analytical database management system**, Apache-2.0 licensed. Engineered for real-time data ingestion and sub-second SQL queries over petabytes of analytical data. **Best for high-throughput real-time analytics.**

- **[DuckDB](https://github.com/duckdb/duckdb)** [<img src="https://img.shields.io/github/stars/duckdb/duckdb?style=social&color=white" alt="DuckDB Stars"/>](https://github.com/duckdb/duckdb/stargazers) 🌟
  **In-process analytical database engine**, MIT licensed. Referred to as the "SQLite for Analytics", featuring fast columnar storage, vectorized execution, and zero zero-external-dependency deployment. **Best for embedded analytical processing.**

- **[Apache Doris](https://github.com/apache/doris)** [<img src="https://img.shields.io/github/stars/apache/doris?style=social&color=white" alt="Apache Doris Stars"/>](https://github.com/apache/doris/stargazers) 🌟
  **High-performance real-time analytical database**, Apache-2.0 licensed. Combines sub-second query performance with simple architecture for real-time reporting, ad-hoc analysis, and log data processing. **Best for real-time enterprise OLAP.**

- **[StarRocks](https://github.com/StarRocks/starrocks)** [<img src="https://img.shields.io/github/stars/StarRocks/starrocks?style=social&color=white" alt="StarRocks Stars"/>](https://github.com/StarRocks/starrocks/stargazers) 🌟
  **Next-generation sub-second analytical database**, Apache-2.0 licensed. Powers real-time analytics across data lakes and transactional systems with MPP architecture and intelligent materialized views. **Best for modern data lakehouse queries.**
